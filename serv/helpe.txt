Practical 3: 0/1 Knapsack
Dynamic Programming
Q1. What is the Knapsack Problem?

Selecting items with given weights and values to maximize total value without exceeding the capacity.

Q2. Why is it called 0/1 Knapsack?

Because an item is either selected completely (1) or not selected (0). Fractions are not allowed.

Q3. Which algorithmic technique is used?

Dynamic Programming.

Q4. What is Dynamic Programming?

A technique that stores solutions to subproblems to avoid repeated calculations.

Q5. What is the DP table used for?

It stores the maximum value achievable using the first i items and capacity w.

Q6. Explain the recurrence relation.
\[
DP[i][w]=
\begin{cases}
DP[i-1][w], & wt_i>w\\
\max(DP[i-1][w],v_i+DP[i-1][w-wt_i]), & wt_i\leq w
\end{cases}
\]

Q7. What is the base condition?

When there are zero items or zero capacity, maximum value is zero.

Q8. What is the time complexity?

O(nW), where n is the number of items and W is capacity.

Q9. What is the space complexity?

O(nW) for the two-dimensional DP table.

Q10. Difference between Fractional and 0/1 Knapsack?

Fractional Knapsack allows partial items and is solved optimally using a greedy strategy. 0/1 Knapsack does not allow partial items and is solved using DP in this implementation.

Q11. Why do we use max() in the program?

To select the better option: include the item or exclude it.

Q12. What is optimal substructure?

An optimal solution can be constructed using optimal solutions to smaller subproblems.

Q13. What is overlapping subproblem?

The same smaller problem occurs repeatedly during computation.

Q14. Why do we use vector<vector<int>>?

To create a two-dimensional DP table dynamically.

Q3. What is backtracking?

Trying possible solutions, rejecting invalid choices and undoing previous choices when necessary.

Q4. How many directions must be checked in your implementation?

Three directions: same column, upper-left diagonal and upper-right diagonal.

Q5. Why do we not check the lower rows?

Because queens are placed row by row, so lower rows are still empty.

Checks whether placing a queen at a particular position is valid.

Q7. What is the base condition?

    return true;


It means all queens have been successfully placed.

Q8. What is backtracking in your code?
board[row][col] = 0;


It removes a previously placed queen when that choice does not lead to a solution.

Q9. What is the worst-case time complexity?

O(N!) as a commonly used upper bound for this row-by-row search.

Q10. What is the space complexity?

O(N²) for the board, plus O(N) recursion stack.

Q11. Can two queens attack each other diagonally?

Yes. Queens can attack horizontally, vertically and diagonally.

Q12. Why does your program ask for the first queen's column?

Because the assignment requires the first queen to be placed before backtracking places the remaining queens.

No. It returns after finding the first valid solution.

1\. What is Fibonacci series? — A sequence in which each number is the sum of the previous two numbers, starting with 0 and 1.

2\. What is recursion? — A function calling itself to solve a smaller instance of a problem.

3\. What is the base condition in your code? — `if(n <= 1) return n;` stops recursive calls.

4\. What is the output of Fibonacci(6)? — 8, because the sequence is 0, 1, 1, 2, 3, 5, 8.

5\. What is the time complexity of recursive Fibonacci? — O(2ⁿ) as an upper bound for naive recursion.

6\. What is the time complexity of iterative Fibonacci? — O(n), because it calculates each term once.

7\. What is the space complexity of recursive Fibonacci? — O(n) due to the recursion call stack.

8\. What is the space complexity of iterative Fibonacci? — O(1), because it uses only three variables.

9\. Why is iterative Fibonacci faster? — It avoids repeated calculations and function-call overhead.

### Practical 2: Huffman Encoding – Greedy

10\. What is Huffman Encoding? — A lossless compression algorithm that assigns variable-length binary codes based on character frequencies.

11\. Who invented Huffman Coding? — David A. Huffman in 1952.

12\. Which algorithmic technique is used? — Greedy Algorithm.

13\. Which data structure is used? — Min-priority queue.

14\. Why do we use a min-priority queue? — To efficiently extract the two nodes with the smallest frequencies.

15\. What is a prefix-free code? — A code in which no complete codeword is the prefix of another codeword.

16\. Why are frequent characters given shorter codes? — To minimize the total weighted encoding length.

17\. What is the time complexity? — O(n log n), where n is the number of distinct characters.

18\. What happens if two characters have equal frequencies? — Multiple valid Huffman trees and code assignments may be possible.

### Practical 3: 0/1 Knapsack – Dynamic Programming

19\. What is the Knapsack Problem? — Selecting items to maximize total value without exceeding the available capacity.

20\. Why is it called 0/1 Knapsack? — Each item is either selected completely or rejected.

21\. Which technique is used? — Dynamic Programming.

22\. What is the recurrence relation? — `DP[i][w] = max(DP[i-1][w], value[i-1] + DP[i-1][w-weight[i-1]])` when the item fits.

23\. What is the base condition? — Zero items or zero capacity gives maximum value zero.

24\. What is the time complexity? — O(nW), where n is the number of items and W is capacity.

25\. What is the space complexity? — O(nW) for the two-dimensional DP table.

26\. Difference between 0/1 and Fractional Knapsack? — 0/1 does not allow partial items; Fractional Knapsack allows partial selection.

27\. Why is `max()` used in the code? — To choose between including and excluding an item.

### Practical 4: N-Queens – Backtracking

28\. What is the N-Queens Problem? — Placing N queens on an N×N chessboard without any two queens attacking each other.

29\. Which technique is used? — Backtracking.

30\. What is backtracking? — Trying a choice, checking its validity and undoing it if it leads to failure.

31\. Why do we check three directions? — To check the same column and both upper diagonals because queens are placed row by row.

32\. What is the base condition? — `row == n` means all queens have been placed successfully.

33\. What does `board[row][col] = 0` do? — It removes a queen when backtracking.

34\. What is the worst-case time complexity? — O(N!) as a commonly used upper bound for row-wise backtracking.

35\. Does your program find all solutions? — No, it stops after finding the first valid solution.

### Practical 5: Quick Sort – Deterministic and Randomized

36\. What is Quick Sort? — A sorting algorithm that partitions elements around a pivot and recursively sorts the partitions.

37\. Which technique does Quick Sort use? — Divide and Conquer.

38\. What is a pivot? — An element used to partition an array into smaller and larger elements.

39\. What is deterministic Quick Sort in your code? — It selects the last element as the pivot.

40\. What is randomized Quick Sort? — It selects a randomly chosen element as the pivot.

41\. What is the average time complexity? — O(n log n).

42\. What is the worst-case time complexity? — O(n²).

43\. When does the worst case occur? — When partitioning repeatedly produces highly unbalanced subarrays.

44\. Is Quick Sort stable? — No, the standard implementation is not stable.

45\. Why do we use `srand(time(0))`? — To initialize the random-number generator with a changing seed.

## Group B – Machine Learning (Questions 46–80)

### Practical 6: Uber Fare Prediction – Linear Regression and Random Forest

46\. What is Machine Learning? — A branch of AI that enables computers to learn patterns from data and make predictions.

47\. What is Regression? — A supervised learning technique used to predict continuous numerical values.

48\. What is the target variable in Uber prediction? — `fare_amount`.

49\. What is Linear Regression? — An algorithm that models a linear relationship between input features and a continuous output.

50\. What is Random Forest Regression? — An ensemble algorithm that combines predictions from multiple decision trees.

51\. What is an outlier? — A data point that significantly differs from the general pattern of the dataset.

52\. What is correlation? — A statistical measure indicating the strength and direction of the relationship between two variables.

53\. What is R² score? — It measures how much variation in the target variable is explained by the regression model.

54\. What is RMSE? — The square root of the average squared prediction error.

### Practical 7: Email Spam Detection – KNN and SVM

55\. What is Classification? — A supervised learning technique that predicts categorical labels.

56\. What is KNN? — An algorithm that classifies a data point using the majority class among its K nearest neighbors.

57\. What is K in KNN? — The number of nearest neighbors considered for prediction.

58\. What is SVM? — Support Vector Machine finds a decision boundary that separates classes with maximum margin.

59\. What are support vectors? — Data points closest to the separating hyperplane.

60\. What is TF-IDF? — A technique that converts text into numerical features based on word importance.

61\. Why is TF-IDF used? — To convert email text into numerical vectors for machine learning.

62\. What is `LinearSVC`? — A linear Support Vector Classification implementation.

### Practical 8: Bank Customer Churn – Neural Network

63\. What is Customer Churn? — When a customer stops using a company's services.

64\. What is ANN? — Artificial Neural Network is a computational model inspired by interconnected biological neurons.

65\. How many hidden layers are in your model? — Two hidden layers containing 16 and 8 neurons.

66\. What is ReLU? — An activation function defined as `max(0,x)`.

67\. What is Sigmoid? — An activation function that converts an output into a value between 0 and 1.

68\. Why is Sigmoid used in the output layer? — To produce a probability for binary classification.

69\. What is an epoch? — One complete pass through the training dataset.

70\. What is batch size in your code? — 32 samples are processed before each weight update.

71\. Which optimizer is used? — Adam optimizer, which adaptively updates neural network weights.

72\. Which loss function is used? — Binary Cross-Entropy for binary classification.

### Practical 9: Diabetes Prediction – KNN

73\. What is the target variable? — `diabetes`, representing the diabetes class.

74\. Why is StandardScaler used? — To standardize features because KNN depends on distance calculations.

75\. What is Euclidean Distance? — The straight-line distance between two points in multidimensional space.

76\. What is the K value in your code? — K = 5.

77\. What is a confusion matrix? — A table showing correct and incorrect classification predictions.

78\. What is Precision? — The proportion of predicted positive cases that are actually positive: TP/(TP+FP).

79\. What is Recall? — The proportion of actual positive cases correctly identified: TP/(TP+FN).

### Practical 10: Sales Data Clustering – K-Means and Hierarchical Clustering

80\. What is the difference between K-Means and Hierarchical Clustering? — K-Means uses centroids and predefined K, whereas Hierarchical Clustering builds a hierarchy of clusters.
